Attribution Accuracy & Technical Reality

This toolkit is designed with strict technical honesty:

  • A click is NOT a conversation: When someone clicks a WhatsApp button, the browser opens WhatsApp with prefilled text. The user can choose to edit or discard that text before sending. A button click is recorded as an unconfirmed_click, not a closed sale.
  • First-touch vs. Last-touch: By default, the library preserves first-touch campaign parameters so multi-visit journeys don't lose initial discovery context, while recording the latest campaign touchpoint separately.
  • Privacy First: Zero fingerprinting, zero cross-site trackers, and zero personal information in local browser storage. Completely configurable storage modes (sessionStorage, localStorage, or memory-only).
