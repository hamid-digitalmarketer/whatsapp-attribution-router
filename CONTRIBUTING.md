# Contributing to WhatsApp Attribution Router

We welcome contributions, bug fixes, and feature improvements from the marketing technology community!

## Development Workflow

1. Fork and clone the repository.
2. Install dependencies:
   - Node: `npm install`
   - Python: `pip install -r backend/requirements-dev.txt`
3. Run tests:
   - Node: `npm test`
   - Python: `python -m pytest backend/tests -v`
4. Lint code:
   - Python: `ruff check backend && ruff format --check backend`
5. Submit a pull request with a descriptive title and summary of changes.
